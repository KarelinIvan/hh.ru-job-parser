📋 hh.ru-job-parser — Парсер вакансий

Личный проект (pet-project) для мониторинга рынка труда. Десктопное приложение с GUI-интерфейсом (PyQt6) для анализа зарплатных вилок по выбранным фильтрам.

Основные функции

- Поиск: загрузка данных через официальное API hh.ru с гибкими фильтрами (город, зарплата, опыт работы и др.).
- Автодополнение городов: умный поиск городов при вводе (поддерживает все города России из базы hh.ru).
- Экспорт в Excel: сохранение результатов в XLSX-файл с корректным форматированием колонок под сводные таблицы.
- Кэширование: список всех регионов загружается один раз при старте приложения (JSON) для ускорения поиска.
- Обработка ошибок: уведомления о проблемах с интернет-соединением или некорректными данными.

✨ Технологии (Стек)

- Интерфейс: PyQt6 6.9+
- API: Официальное API hh.ru (с соблюдением правил).
- Анализ данных: Pandas 2.2+, Requests 2.32+.

🚀 Запуск проекта

Локальный запуск
- Установите зависимости: устанавливаются через requirements.txt.
- Запустите приложение: python main.py

💡 Совет: Для запуска на Windows может потребоваться установка дополнительных библиотек для компиляции C‑расширений (pip install pyqt5‑tools), если у вас нет Visual Studio Build Tools.
